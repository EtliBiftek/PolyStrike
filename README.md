# PolyStrike

PolyStrike, low-poly görsel stile sahip rekabetçi bir taktiksel FPS projesidir.

## Teknoloji

- Unity 6.3 LTS
- Windows x64
- C#
- GitHub Actions + GameCI

## İlk hedef

İlk oynanabilir sürümde temel FPS hareketi, kamera kontrolü, can sistemi, hitscan silah altyapısı ve dosya tabanlı yerelleştirme sistemi bulunacak.

## Dil dosyaları

Oyundaki kullanıcıya görünen metinler `Assets/StreamingAssets/Languages` altındaki `.txt` dosyalarından okunur. Başlangıç dili Türkçedir.
